bash

cjpm run curl2py "curl https://api.example.com"

### 五、支持的 curl 参数

**支持url包含的可能参数：**
如：

| 参数                 | 说明      | 示例                                    |
| ------------------ | ------- | ------------------------------------- |
| `-X` 或 `--request` | HTTP 方法 | `-X POST`                             |
| `-H` 或 `--header`  | 请求头     | `-H 'Content-Type: application/json'` |
| `-b` 或 `--cookie`  | Cookie  | `-b 'session=abc123'`                 |
| `-d` 或 `--data`    | 请求体     | `-d '{"name":"test"}'`                |
| `--data-raw`       | 原始请求体   | `--data-raw 'raw text'`               |
| `--url`            | 指定 URL  | `--url https://api.com`               |
| 等                  |         |                                       |

### 六、生成代码风格

**GET 请求（无参数）：**

python

import requests
response = requests.get('https://api.example.com')
print(response.text)

**GET 请求（带参数）：**

python

import requests
headers = {
    'accept': '*/*',
}
cookies = {
    'session': 'abc123',
}
response = requests.get(
    'https://api.example.com',
    headers=headers,
    cookies=cookies,
)
print(response.text)

**POST JSON：**

python

import requests
import json
headers = {
    'Content-Type': 'application/json',
}
data = {
    'name': 'John',
    'age': 30,
}
response = requests.post(
    'https://api.example.com/users',
    headers=headers,
    json=data,
)
print(response.text)

**POST Form：**

python

import requests
headers = {
    'Content-Type': 'application/x-www-form-urlencoded',
}
data = {
    'username': 'admin',
    'password': '123456',
}
response = requests.post(
    'https://api.example.com/login',
    headers=headers,
    data=data,
)
print(response.text)

### 七、使用示例

**示例1：基础 GET**

bash

cjpm run curl2py "curl https://httpbin.org/get"

输出标准 Python 代码。

**示例2：带 Headers 和 Cookie**

bash

cjpm run curl2py "curl https://api.bilibili.com/x/v2/reply/wbi/main -H 'accept: */*' -b 'SESSDATA=abc123; bili_jct=def456'"

**示例3：POST JSON**

bash

cjpm run curl2py "curl -X POST https://api.example.com/users -H 'Content-Type: application/json' -d '{\"name\":\"test\"}'"

**示例4：从文件读取（用于复杂命令）**

bash

# 将复杂的 curl 保存到 curl.txt
cjpm run curl2py -f ./curl.txt -o ./api.py

### 八、错误处理

bash

❌ 错误: 未提供 curl 命令
💡 提示: 请粘贴 curl 命令，或使用 -f 从文件读取
❌ 错误: 文件不存在 ./curl.txt
💡 提示: 请检查文件路径
⚠️  警告: 检测到 Cookie 包含敏感信息
🔒 建议: 将 Cookie 值替换为环境变量
